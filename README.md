## 1. Tic-Tac-Toe

Реализация игры "Крестики-нолики" с графическим интерфейсом на Pygame. Игрок управляет крестиками, компьютер — ноликами.

### Возможности:

- Два режима сложности: случайные ходы (лёгкий) и минимакс (сложный)
- Управление мышью и клавиатурой
- Визуальная индикация состояния игры

### Запуск:

```bash
pip install pygame
python main.py
```
Управление:
| Действие |	Способ |
|-------|----------|
| Ход	| Клик по клетке |
| Перезапуск	| Кнопка «Новая игра» или клавиша R |
| Смена режима |	Кнопки «Лёгкий»/«Сложный» |

## 2. Typing Speed Test
Приложение для измерения скорости печати на клавиатуре. Пользователю предлагается случайное предложение, которое необходимо ввести с максимальной точностью.

Возможности:
Случайная выборка предложений из встроенной базы

Расчёт времени, точности (%), количества символов и скорости (WPM)

Возможность повторного прохождения теста

Запуск:

```bash
pip install pygame
python main.py
```
Требования к файлам:
end.jpg, background.jpg, icon.jpg должны находиться в директории со скриптом.

---

| Порядок работы: |
|--------------------|
| Клик по полю ввода запускает таймер|
| Ввод текста в поле |
| Enter завершает тест и выводит статистику |
| Reset для новой попытки|

## 3. Todo CLI
Консольное приложение для управления списком задач. Данные сохраняются в файл todo.txt.

Возможности:
Добавление задач с автоматической нумерацией

Просмотр текущих задач

Удаление задач по идентификатору

Автосохранение в локальный файл

Установка:
```bash
git clone https://github.com/ваш-логин/todo-cli.git
cd todo-cli
pip install click
```

Команды:
| Команда | Действие |
|--------|--------------|
| tasks	| Вывод списка задач|
| add	| Добавление задачи|
| done | Удаление задачи по ID|


Примеры:
```bash
# Добавление задачи
python todo.py add -add "Купить продукты"

# Просмотр задач
python todo.py tasks

# Удаление задачи
python todo.py done -fin 1
Формат хранения:
Файл todo.txt создаётся автоматически в директории со скриптом.
```

## 4. Password Generator
Генератор случайных паролей. Использует стандартную библиотеку Python.

Возможности:
Генерация пароля длиной 16 символов

Набор символов: латиница (верхний и нижний регистр) + цифры

Не требует установки внешних зависимостей

Запуск:
```bash
python password_generator.py
```
Пример вывода:
```
aB3xK7pQ9wE2rT5y
```
Рекомендации по доработке:
Замена random на secrets для криптостойкости

Добавление специальных символов

Настройка длины пароля через аргументы командной строки

Исключение визуально схожих символов

Требования к окружению
---
| Компонент |	Требование |
|--------|------------|
| Python	| 3.7 или выше |
| Pygame	| для проектов 1 и 2|
| Click	| для проекта 3 |
